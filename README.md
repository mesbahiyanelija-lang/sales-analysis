# sales-analysis Project

## Overview
Analysis of superstore sales data using Python and Pandas.

## Tools used
- Python
- Pandas
- Matplotlib

## Analysis
- Sales by Category
- Sales by Region
- Sales by Region and Category
- Monthly Sales Trend
  
## Key Findings
- Technology is the top performing category
- West and East regions leads in sales
- Overall upward sales trend from 2015 to 2018
